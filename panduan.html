      Lacak Pesanan
      Panduan pemesanan

      Alur cetak dari katalog sampai pesanan selesai

      Website ini dipakai untuk memilih produk, memahami spesifikasi awal, dan melacak progres. Detail order tetap dikunci lewat WhatsApp bersama admin.

      Mulai dari sini

      Cara pesan

      Ikuti urutan ini jika Anda baru pertama kali pesan cetak lewat website.

      01

      Pilih produk

      Buka katalog, bandingkan bahan, harga acuan, dan opsi aktif. Masuk ke halaman detail produk yang paling sesuai.

      02

      Pesan via WhatsApp

      Gunakan tombol pesan di halaman detail agar nama produk dan spesifikasi ikut terbawa ke chat admin.

      03

      Kirim file dan konfirmasi

      Kirim file desain, jumlah, ukuran, bahan, finishing, dan kebutuhan deadline. Admin akan mengecek sebelum produksi.

      04

      Lacak progres

      Setelah pesanan dicatat, gunakan halaman lacak pesanan untuk melihat status produksi dan mengunduh nota digital.

      Sebelum kirim file

      Format dan checklist desain

      File yang bisa dikirim

      PDF CDR AI PSD JPG PNG

      Jika ragu, kirim file yang Anda punya. Admin akan bantu cek apakah file sudah aman untuk dicetak.

      Agar hasil lebih aman

      • Resolusi 300 DPI jika tersedia, supaya gambar tidak pecah.
      • Mode warna CMYK untuk warna cetak yang lebih siap produksi.
      • Bleed 3 mm, area lebih untuk hasil potong yang rapi.

      Jika belum punya file final

      • Jelaskan ukuran, bahan, dan tujuan pemakaian.
      • Kirim contoh referensi bila ada.
      • Sebutkan deadline sejak awal agar estimasi lebih realistis.
      Status produksi

      Arti status di halaman tracking

      Pending

      Pesanan sudah dicatat dan menunggu pengecekan file atau konfirmasi detail.

      Proses desain

      Tim sedang menyesuaikan desain atau menyiapkan file sebelum masuk mesin cetak.

      Dicetak

      Pesanan sudah masuk tahap produksi cetak. Perubahan detail biasanya sudah tidak bisa dilakukan.

      Selesai

      Pesanan siap diambil atau ditindaklanjuti sesuai kesepakatan dengan admin.

      Siap mulai?

      Untuk pesanan baru, mulai dari katalog. Jika kebutuhan Anda khusus, langsung konsultasi lewat WhatsApp.

      Buka katalog Konsultasi via WhatsApp Lacak pesanan

      Catatan penting

      • Pastikan nama file dan isi desain sudah benar sebelum produksi dimulai.
      • Perbedaan warna kecil antara layar dan hasil cetak bisa terjadi.
      • Untuk jumlah sedikit, deadline dekat, atau spesifikasi khusus, konsultasikan dulu.
      • Simpan nomor pesanan untuk tracking dan unduh nota digital.
